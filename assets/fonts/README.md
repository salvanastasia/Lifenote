# Fonts

Download the following fonts and place them in this directory:

1. **DM Mono Regular** - Download from [Google Fonts](https://fonts.google.com/specimen/DM+Mono)
   - File name: `DMMono-Regular.ttf`

2. **Handlee Regular** - Download from [Google Fonts](https://fonts.google.com/specimen/Handlee)
   - File name: `Handlee-Regular.ttf`

## How to download:

1. Go to the Google Fonts links above
2. Click "Get font" or "Download family"
3. Extract the TTF files
4. Rename them exactly as specified above
5. Place them in this `assets/fonts/` directory

The app will not run without these fonts!
